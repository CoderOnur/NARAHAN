# Privacy Policy for Narahan Discord Bot

Last updated: September 21, 2026

1. Overview
Narahan ("the Bot") is committed to protecting user privacy. This Privacy Policy outlines our practices regarding data collection, usage, and retention.

2. Data Collection & Usage
The Bot DOES NOT store, log, or persist any personal user data, messages, or activity history on external servers or databases. 
- Message contents processed via Message Content Intent are analyzed transiently in real-time solely to execute user-requested commands and are immediately discarded.
- Server member information (such as User IDs and Server IDs) is processed temporarily in memory to perform functional bot actions (e.g., welcome messages, role assignments, economy game logic) and is not stored permanently.

3. Third-Party Data Sharing
We do not sell, share, or transfer any user data to third parties.

4. Data Retention
Since no personal data or message content is stored outside Discord's ecosystem, users do not need to request data deletion.

5. Contact
If you have any questions regarding this Privacy Policy, please contact the bot developer via Discord.
